Функции и адресация в электронных таблицах

1. Виды адресации (ссылок)

При копировании формулы Excel сдвигает ссылки на столько строк и столбцов, на сколько сдвинулась сама формула. Знак $ «замораживает» то, перед чем стоит.

  • Относительная A1 — меняются и столбец, и строка.
  • Абсолютная $A$1 — не меняется ничего.
  • Смешанная $A1 — закреплён столбец A; A$1 — закреплена строка 1.

Формулу =B2*$E$1 из C2 скопировали вниз в C3: B2 сдвинулась на одну строку → B3, а $E$1 осталась на месте.

Клавиша F4 переключает вид ссылки по кругу: A1 → $A$1 → A$1 → $A1 → A1.

Когда нужна абсолютная ссылка? Когда все формулы столбца берут одно и то же значение из одной ячейки (норма, курс, процент скидки).

2. Математические функции

Аргументы функции разделяются точкой с запятой ;, диапазон записывается через двоеточие A1:A5.

  • =СУММ(A1:A5) — сумма чисел диапазона → 20
  • =ABS(A2) — модуль числа (без знака «минус») → 8
  • =КОРЕНЬ(A3) — квадратный корень → 5. Корень из отрицательного числа даёт ошибку #ЧИСЛО!
  • =СТЕПЕНЬ(A4;3) — число в степени: 2³ → 8
  • =СУММЕСЛИ(A1:A5;">0") — сумма только тех чисел, что удовлетворяют условию → 28

СУММЕСЛИ с двумя диапазонами: =СУММЕСЛИ(диапазон_условия; "условие"; диапазон_суммирования)

=СУММЕСЛИ(B2:B5;"да";C2:C5) — сложить баллы только тех, кто сдал проект: 8 + 7 = 15.

3. Логическая функция ЕСЛИ

=ЕСЛИ(лог_выражение; значение_если_истина; значение_если_ложь)

Excel проверяет условие. Если оно верно (ИСТИНА) — выводит второй аргумент, если нет (ЛОЖЬ) — третий.

Операции сравнения: > больше, < меньше, = равно, >= больше или равно (не меньше), <= меньше или равно (не больше), <> не равно.

В B2: =ЕСЛИ(A2>0;"положительное";"отрицательное"). Для 0 условие 0>0 ложно, поэтому выведется «отрицательное» — будьте внимательны с границей!

Формулу с ЕСЛИ тоже копируют маркером заполнения: ссылки в ней сдвигаются по тем же правилам. Если условие сравнивает с одной ячейкой (порог, норма), ссылка на неё должна быть абсолютной: =ЕСЛИ(A2>=$D$1;"зачёт";"незачёт").

Что может быть значением

  • текст — обязательно в кавычках: "зачёт"
  • число: 5, 0
  • ссылка или выражение: A2, A2*0,9
  • функция: КОРЕНЬ(A2), ABS(B2-C2)
  • пусто: ""
Частые ошибки: текст без кавычек (=ЕСЛИ(A1>5;много;мало)), запятая вместо точки с запятой, перепутаны истина и ложь, «не меньше 6» записано как >6 вместо >=6.
