1. Матрёшка и очередь

Откройте матрёшку — внутри такая же матрёшка, только меньше. Откройте её — снова матрёшка, ещё меньше. И так до самой маленькой, которая уже не открывается. На ней всё и заканчивается.

Ещё пример. Вы стоите в длинной очереди и хотите узнать, какой вы по счёту. Вы спрашиваете стоящего впереди: «Ты какой по счёту?» Он не знает и спрашивает того, кто впереди него… Первый в очереди отвечает сразу: «Я первый!» Ответ идёт обратно: «Я второй», «Я третий»… И вы узнаёте свой номер: его номер + 1.

Рекурсия — это способ решения задачи, когда задача сводится к такой же задаче, но меньшего размера.
Рекурсивная функция — это функция, которая вызывает саму себя.

3. Две обязательные части

    
В каждой рекурсивной функции обязательно есть две части:

    
Базовый случай (условие остановки) — самая простая ситуация, когда ответ известен сразу, без новых вызовов.

    Это «самая маленькая матрёшка» и «первый в очереди».

    
Рекурсивный шаг — функция вызывает саму себя, но для меньшего значения (n − 1, n // 10 …) и из полученного ответа строит свой.

    Это «открыть матрёшку» и «спросить того, кто впереди».

    
Шаблон

    

    
⚠️ Если забыть базовый случай, функция будет вызывать себя снова и снова. Python остановит программу с ошибкой RecursionError (по умолчанию разрешено около 1000 вложенных вызовов).

  


  

    
4. Пример 1. Сумма чисел от 1 до n

    
Сумма от 1 до 4: 1 + 2 + 3 + 4 = 10. Заметим: сумма до 4 = 4 + сумма до 3. А сумма до 3 = 3 + сумма до 2… Сумма до 1 равна просто 1.

    

      

        

          
Математика

          
S(1) = 1 ← базовый случай

          
S(n) = n + S(n − 1) ← шаг

        

      

      



      

    

    
Как считается summa(4):

    
summa(4) = 4 + summa(3)
         = 4 + 3 + summa(2)
         = 4 + 3 + 2 + summa(1)
         = 4 + 3 + 2 + 1  = 10

    
  


  

    
5. Пример 2. Факториал

    
Факториал числа n (пишут n!) — произведение всех чисел от 1 до n: 4! = 1 · 2 · 3 · 4 = 24.

    Заметим: 4! = 4 · 3!, а 1! = 1.

    

      

        
Математика

        
1! = 1 ← базовый случай

        
n! = n · (n − 1)! ← шаг

      



    

    
Посмотрите: функция fact устроена так же, как summa. Отличие одно: * вместо +.

    
Для любознательных: а 0! ?
      
В математике считают, что 0! = 1. Если нужно, чтобы функция работала и для 0, базовый случай пишут так: if n <= 1: return 1.

7. Пример 4. Когда n только считает вызовы

    
Бывает, что n не участвует в вычислении. Посмотрите на рекурсивный шаг: в выражении 3 * h(n - 1) нет действий с n — n только уменьшается и считает, сколько раз выполнится умножение на 3.



    
h(3) = 3 * h(2)
     = 3 * 3 * h(1)
     = 3 * 3 * 3 * h(0)
     = 3 * 3 * 3 * 1  = 27

    
Снизу вверх: h(0) = 1 → h(1) = 3 → h(2) = 9 → h(3) = 27. Умножили на 3 ровно 3 раза — столько, сколько было n.

    
⚠️ Не путайте: 3 * h(n - 1) — умножаем на 3; n * h(n - 1) — умножаем на n (это факториал).

    

    
  


  

    
8. Трассировочная таблица: как выполняется рекурсия

    
🔑 Главная идея. Каждый вызов функции — это отдельная «копия» со своим собственным n (как отдельный ящик со своей переменной n).
    Компьютер всё делает за долю секунды, но порядок вычислений такой же, как в примере 2 * (3 + 4): умножить нельзя, пока не посчитаны скобки.
    Так и в строке return 4 + summa(3): сложить нельзя, пока не известно значение summa(3). Поэтому Python сначала вычисляет summa(3), а сложение откладывает — строка остаётся не досчитанной.
    Когда summa(3) вернёт число, Python возвращается к отложенной строке и досчитывает её.

  2. sum_even(n) — сумма чётных чисел n + (n − 2) + … + 2, n чётное. (sum_even(8) → 20)
    3. 
      
  3. countdown(n) — процедура: выводит n, n − 1, …, 1, а потом «Старт!». (countdown(3) → 3 2 1 Старт!)

Подсказка
      
1) Как summa, только прибавляем n * n.

      2) Числа уменьшаются на 2: sum_even(n - 2). Остановиться при n <= 0 и вернуть 0.

      3) Если n == 0 — выводим «Старт!», иначе выводим n и вызываем countdown(n - 1). Здесь return не нужен: это процедура.

    

  







  

    
🔍 Как работает рекурсия — по шагам

    
Компьютер выполняет всё мгновенно — здесь то же самое показано «в замедленной съёмке». Сначала вызовы уходят вглубь (таблица заполняется сверху вниз), пока не сработает условие остановки. Потом отложенные строки досчитываются обратно (столбец «Возвращает» заполняется снизу вверх).
